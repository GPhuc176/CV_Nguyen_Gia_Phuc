# Nguyen Gia Phuc - Online CV

A one-page CV website for **Nguyen Gia Phuc**, AI / Machine Learning Intern and AI student at FPT University Da Nang.

**Live site:** https://gphuc176.github.io/MyCV/

## About

This repository hosts my CV as a static web page, with a downloadable PDF version. The page covers my education, skills, certifications, and academic projects in computer vision, cross-modal retrieval, sentiment analysis, and machine learning.

## Features

- Responsive layout for desktop and mobile
- Print-ready: printing the page keeps the CV look on A4
- One-click PDF download
- Links to the GitHub repository of every project

## Repository Structure

```
.
├── index.html                 # the CV page (HTML and CSS in one file)
├── photo.jpg                  # profile photo
├── CV_Nguyen_Gia_Phuc.pdf     # downloadable PDF version
└── README.md
```

## Run Locally

No build step needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/GPhuc176/MyCV.git
cd MyCV
```

## Tech Stack

HTML5 and CSS3 (no framework, no JavaScript), hosted with GitHub Pages.
